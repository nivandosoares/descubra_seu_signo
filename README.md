# Descubra Seu Signo

Exercício em PHP que consulta um arquivo XML para identificar o signo informado pela data de nascimento.

**Arquivos principais**

- [index.php](<index.php>)
- [show_zodiac_sign.php](<show_zodiac_sign.php>)
- [signos.xml](<signos.xml>)

## Desenvolvimento local

Com PHP instalado, execute `php -S localhost:8000` na raiz e abra a página inicial no navegador.
